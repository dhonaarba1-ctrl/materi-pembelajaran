Petunjuk Presentasi

  • Tekan Selanjutnya atau Sebelumnya untuk berpindah slide.
  • Tekan Beranda untuk memilih topik, dan Keluar untuk kembali ke sampul.
  • Di HP, gulir ke bawah untuk membaca konten panjang; bisa juga geser kiri atau kanan untuk pindah slide.
  • Jawab latihan klasifikasi SWOT, coba strategi, isi LKPD, dan kerjakan kuis 12 soal.
  • Tombol Suara membacakan isi slide menggunakan fitur browser apabila tersedia.
  • Gambar dan materi tersimpan di file HTML, sehingga dapat digunakan tanpa internet.
